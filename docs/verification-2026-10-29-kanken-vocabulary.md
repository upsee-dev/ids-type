# 漢検一級までを目安にした漢字・熟語の拡充

2026-10-29。アプリ内の日本語タブと、iOS・Androidの「日本語拡張フリック」が共通で使う変換辞書を拡充。

## 収録内容

- 日本語の読み・表記: **1,631,260組 → 1,770,673組（139,413組増）**。
- JMdictの漢字を含む語彙244,439組を取り込み対象に拡張。二字熟語・四字熟語・古語・異表記を含み、使用頻度による足切りをしない。
- KANJIDIC2の完全な訓読みから、送り仮名付き表記に加えて単漢字だけも選べるように補足。訓読み属性を維持するため、4文字以上の完全一致の優先も働く。
- 外国語76,825組、15分類のIDと保存済みの順序、外国語の初期オフを維持。
- JMdictの追加語は基本を「その他の漢字」とし、明示された熟字訓・自然分野等の分類も併記。既存のMozcコストを高く上書きしない。

## 照合範囲

[漢検の公式審査基準](https://www.kanken.or.jp/kanken/grades/overview/)では、一級の目安を常用漢字を含む約6,000字・JIS第一/第二水準としている。

- JIS X 0208第一水準: 2,965/2,965字。
- JIS X 0208第二水準: 3,390/3,390字。
- 常用漢字: 2,136/2,136字。

いずれも単漢字検索の存在と、外国語を有効にしない日本語フリックの単漢字候補の存在を確認。常用漢字とJISの集合は重なるため加算しない。各文字に少なくとも一つの日本語の読みがあることの確認であり、公式の全音訓・全熟語との突合ではない。

[公式FAQ](https://faq-kanken.dga.jp/dantai-sprt/faq_detail.html?id=1010040&page=1)は一級・準一級の配当漢字について書籍『漢検要覧 1／準1級対応』を案内している。本実装は公式の級別配当表や全出題語一覧の転載ではなく、個別語に推定した級を付けない。公式全出題語の網羅認定を意味しない。

集計は `data-src/japanese/kanken-coverage.json` と `coverage.json`。JMdict取り込み段階の新規組数136,564、単漢字訓読み補足段階の新規組数7,918は後段のJMnedict等と重複するので、足し算して最終増分にはしない。漢字4文字の表記26,223組は、すべてが意味上の四字熟語だと断定した数ではない。

## 読みと表記の制限

`scripts/jmdict_words.py`で `re_restr` と、同じ語義に属する `stagk` / `stagr` の組み合わせを尊重する。`re_nokanji` の読みから漢字表記を生成しない。`gikun`タグがない通常の音読み熟語を、熟字訓として優先しない。出典にない読みを意味や構成漢字から合成しない。

原資料は固定済みのJMdict / KANJIDIC2。SHA-256照合と既存のCC BY-SA 4.0の表示を維持し、アプリ内の出典画面と同梱ライセンスに語彙拡充を追記。[EDRDGライセンス](https://www.edrdg.org/edrdg/licence.html)。
